# High Rise Interiors — Assets Directory

This folder is designed to host your local photography, brand marks, and design assets.

### Recommended Local File Structure:
- `assets/images/rooms/` — High-resolution photos for Double-Height Living, Master Suite, Island Kitchen, Closets, Dining.
- `assets/images/portfolio/` — Villa and apartment project photos for the lookbook.
- `assets/images/materials/` — Workshop, carpentry, and European hardware textures.
- `assets/images/brands/` — Partner developer and community logos (Rajapushpa, My Home, Aparna, EIPL, GHM).
- `assets/images/hero/` — Full-width 1920x1080 hero background slides.

To replace any online Unsplash image with your own local photo, simply copy your JPG/WebP/PNG into this folder and update the `src="..."` or `background-image: url('assets/images/...')` attribute in [index.html](file:///c:/Users/YUVARAJ/OneDrive/Desktop/HRI_2/index.html).
